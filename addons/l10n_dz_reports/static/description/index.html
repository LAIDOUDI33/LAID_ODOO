Déclarations Fiscales Algériennes

Module l10n_dz_reports pour Odoo 19.4
Mensuel Trimestriel Annuel

📋 Vue d'ensemble

Ce module fournit un système complet de déclarations fiscales algériennes pour Odoo 19.4, conforme au Code des Impôts Directs et Taxes Assimilées (CIDTA) et au Code de la TVA (CTVA). Il permet de générer les 4 principales déclarations fiscales requises par l'administration fiscale algérienne.

🧾 G50 - TVA

Déclaration mensuelle ou trimestrielle de la Taxe sur la Valeur Ajoutée

💰 G1 - IRG

Retenue à la source sur salaires avec barème progressif

🏢 G2 - TAP

Taxe sur l'Activité Professionnelle trimestrielle

📊 G4 - IBS

Impôt sur les Bénéfices des Sociétés annuel

⚡ Fonctionnalités Principales

  • Calcul automatique des montants depuis les écritures comptables
  • Gestion multi-périodicité: Mensuelle, Trimestrielle, Annuelle
  • Workflow complet: Brouillon → Calculé → Soumis → Payé
  • Rapports PDF conformes aux formulaires officiels DGI
  • Suivi des acomptes provisionnels pour IBS et TAP
  • Gestion du crédit de TVA reportable
  • Intégration CNAS/CASNOS pour les cotisations sociales
  • Barème IRG intégré avec abattements automatiques
  • Exonérations sectorielles (Zone Sud, Agriculture, Start-up)
  • Multi-sociétés supporté nativement

📑 Détails des Déclarations

Code Type d'Impôt Périodicité Taux Applicables

📜 Conformité Réglementaire

Ce module est conçu en stricte conformité avec:

  • Arrêté du 26 juillet 2008 portant adoption du Système Comptable Financier (SCF)
  • Loi de Finances Complémentaire 2009 - Mise en place SCF
  • Ordonnance 75-35 du 29 avril 1975 - Code des Impôts Directs (TAP)
  • Loi de Finances 2024 - Révision taux IBS à 19%/26%
  • Code de la TVA Algérien (CTVA) - Dispositions TVA collectée/déductible
  • Convention CNAS - Cotisations sociales salariales/patronales
